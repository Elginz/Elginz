## 👋 About me
 
I'm a Computer Science (Machine Learning & AI) graduate and a **Google Cloud Professional Cloud Architect**, working where AI engineering meets cloud infrastructure. I want to build production-grade AI systems, and I care about running them reliably, securely and affordably.
 
## 🚀 What I work on
 
- 🤖 **Multi-agent AI systems** on Google Cloud (Vertex AI, Gemini, Agent Development Kit)
- 🔎 **RAG pipelines** and **LLM evaluation** workflows (LLM-as-a-Judge, Langfuse tracing)
- ☁️ **Cloud infrastructure as code** with Terraform, zero-trust networking and hybrid cloud
- 💸 **Cost attribution and TCO analysis** for AI and cloud workloads
- 🎤 **Customer-facing technical work**: workshops, buildathons and executive sessions
